## Decisions
- Batch stores per job rather than one job per store: each job pays one `pnpm install` and minute rounding (budgeted-runner policy); 300 stores = 38 jobs, not 300.
- "Older than two releases" = more than two tags dated after the PR was opened: red at the third. Annotated tags give the date (CHANGELOG step 4 now says `git tag -a`).
- The hand-edited case pushes nothing (the owner's work stays); the old-PR case still updates, so the PR carries the latest version.
- Q4 unanswered: all three listed stores paused (productos dead; lenceria and mascota until O24's history adoption, F13). lenceria is the ring-0 canary. No store added.
- Token: recommend a GitHub App (decisions item 4); nothing created.

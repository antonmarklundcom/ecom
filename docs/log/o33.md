## Decisions
- `product_id` / `variant_id` use 0 for "none", not NULL: MySQL UNIQUE lets two NULL rows share a key and the upsert would stop adding. Hence no FK; a deleted product shows as "Producto borrado".
- Surrogate `id` PK plus UNIQUE (not a composite PK): the backup pages by one numeric column.
- The listener lives in `src/app/layout.tsx` (skin, like every UI file): a store that redesigned the layout must add `<ContadorConsultas />` by hand — written in NEW-STORE.md §4f.
- CSV is a session-checked GET route, not a server action: counts with no personal data, behind `dashboard`, not `exports`.
- `tests/unit/security-review.test.ts`: `/api/consulta` is the second named exception to "every API route checks a secret or session", with its own test (origin and limit before counting, 204 only).
- Origin `tarjeta`, `guia`, `contacto` exist in the enum; no card, guide or contact page has a WhatsApp link in the template yet. O34/O35 add `atributosConsulta("guia" | "contacto")` to theirs.

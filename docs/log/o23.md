## Decisions
- Skin ownership is decided by content fingerprint, not by a list of files a store says it changed: it needs no input from the store and stays right after every sync.
- Migrate photos only after deploying the R2 code: the old code cannot draw `r2:` references; the new one draws old ones as placeholders.
- Preflight in the harness blocks only on R2 (no bucket, plan §7 item 6) — accepted as green; no fake credentials, since the canary would call Cloudflare.
- Sur's data DB was recreated from scratch after case 1, as NEW-STORE.md says; its migrate fingerprint is therefore trivially identical. Norte carries the real one (0024 + 0025 over T0 data).
- `vitest.config.mts` (not in Owns) got the setup file: the test policy needs it, and it is one line per project.
- Node 24.19.0 (the only one installed) for the clean clone, not `.nvmrc` 22; `engines` allows both.
